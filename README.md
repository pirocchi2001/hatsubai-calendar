# 新商品発売スケジュール
玩具・ホビー・キャラクターグッズの発売一覧。表示・絞り込み・編集・PDF出力ができます。

- `data.json` … 公開データ（バンダイ公式カレンダー由来 `b-*` ＋ 手動調査 `m-*`）
- 毎週 水・金 06:00(JST) に GitHub Actions が `b-*` を自動更新（`scripts/update_bandai.py`）
- 手動調査分は `data.json` を直接編集、または画面の「編集モード」→「JSON書き出し」で作った JSON を `data.json` に置き換えて commit
- 画面での編集はその端末のブラウザにのみ保存されます（公開データは変わりません）
